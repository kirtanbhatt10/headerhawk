# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a
vulnerability** button (Security → Advisories) or by email to
kirtan11bhatt@gmail.com. I aim to acknowledge reports within 3 days.

Wrong grades or false negatives that are not a security issue in headerhawk
itself can go in a normal issue.

## Responsible use

Only audit sites you own or have permission to test. headerhawk sends ordinary
GET requests, but repeated automated scanning of third-party sites may break
their terms of service.
